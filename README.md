# TouchGrass 🌱
> *Go for a walk.*

A clean, 100% offline digital wellbeing app for Android designed to help you break free from the screen and reconnect with the real world.

---

## ✨ Features
- **100% Offline & Private**: Zero internet permissions (`android.permission.INTERNET` is not requested). Zero tracking, zero telemetry, zero cloud sync.
- **Continuous Studio Animations**: 60 FPS vector animations that dynamically shift with your focus duration.
- **Dual Lock Modes**:
  - *Duration Mode*: Quick 1 to 120-minute sessions.
  - *Until Mode*: Set a specific target time (e.g., 5:00 PM).
- **Tamper-Proof Protection**: Optional Device Admin to prevent impulse uninstallation during active sessions.
- **Passcode Shield**: Secure salted SHA-256 local passcode verification for early unlock.
